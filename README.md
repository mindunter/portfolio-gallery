# Mindunter Studios: Sphere Gallery

A 3D sphere of posters from [mindunter.framer.website](https://mindunter.framer.website), built with the
[DesignRigs 3D Gallery Generator](https://www.designrigs.com/3d-gallery-generator).

Live: https://mindunter.github.io/portfolio-gallery/

- Drag to spin, scroll or pinch to zoom, click a poster to view it fullscreen.
- Settings live in `gallery.config.js`.
- `index.html` adds a responsive fit so the whole globe stays in frame on phones.
- `designrigs-gallery.js` has one fix (marked "Mindunter fix") so posters face the camera instead of showing mirrored.
